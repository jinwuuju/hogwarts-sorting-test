## 배포

GitHub Pages에서 `main` 브랜치의 루트(`/`)를 게시합니다. `index.html`을 수정하면 자동으로 다시 배포됩니다.

## 원본 유지

제공된 HTML의 화면, 암호 입력, 문항 및 결과 계산을 유지했습니다. 배포용 파일명, 페이지 제목, 한국어 언어 속성만 설정했습니다.

암호 확인은 브라우저에서 실행되는 장면 연출이며 보안용 접근 제한이 아닙니다. 아이콘과 글꼴은 외부 CDN을 사용합니다.
